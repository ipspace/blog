    Configuration management on IOS(-XE) seems absolutely broken.

    Hi Ivan!

    ~15 years ago I ran into similar disappointing/broken behavior with config rollback.

    I got the same "aborted after 5 passes" message, but not due to PKI. This instance was trying to revert some timer command with "no".

    Problem was this command couldn't be backed out that way. Restoring the default behavior required the operator to set the default value.

    I was astounded at the time to learn that the underlying engine boiled down to diff + sed 's/^/no /', and I concluded that I could never trust it.
