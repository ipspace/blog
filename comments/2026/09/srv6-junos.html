    About the SRv6 block configuration, I might be completely wrong but this is how I understand the thing. In micro-SID the header compression is achieved by not repeating the most significant bits of the SID, that is, the Locator Block. In order to make that work within an SR domain all the routers need to share the same block. How could that work if one router considers the first 32 bits to represent the block while some other router considers the first 48 bits to be the block?

    I guess configuring the block explicitly is not required if you are sure that all the routers use the industry standard F3216 format, but I don't know if any standard states that F3216 must be the default format. As can be seen in the example, your lab router advertises the F3216 locator structure.

    Finally, explicitly configuring the block becomes even more relevant if one uses Flex Algos.
